# Release Notes — v1.0.0

## Summary

`v1.0.0` is the frozen recruiter-facing release of the OpenAI and Anthropic LLM API Cost FinOps Platform.

The implementation baseline is commit `c2a2449c5e8dbba0237dd9abd8be3b747a247e26`. M20 adds only release, evidence, tracker, and Phase 2 planning artifacts; it does not change v1 analytical calculations.

## Included capabilities

- Provider usage, provider cost, and invoice ingestion
- Effective-dated model pricing
- Usage-estimated, provider-reported, and invoice-billed reconciliation
- Application, department, and cost-center allocation
- Request telemetry, retries, failures, caching, and batch analysis
- Token and request unit economics
- Optimization evaluation gates
- Experiment financial governance
- Eighteen end-to-end controls
- Shared guarded BigQuery deployment
- Power BI semantic model and four report pages
- Reproducible source generation, tests, linting, and GitHub Actions

## Frozen portfolio results

- Invoice-billed cost: **$20,340.15**
- Provider-reported cost: **$20,243.73**
- Logical requests: **347,775**
- Telemetry attempts: **369,921**
- Retry attempts: **22,146**
- Allocation coverage: **approximately 99.95%**
- Modeled annualized opportunity: **approximately $9.29K**

## Validation

- Source generation passed.
- 189 tests passed.
- Repository CI passed.
- Local `main` matched `origin/main` at the captured baseline.
- The working tree was clean.
- Required Power BI support files, PBIP artifacts, and screenshots were committed.

## Important limitations

The release uses controlled non-confidential data and does not claim actual company savings, ROI, productivity, revenue, or customer outcomes. Public CI does not execute authenticated BigQuery jobs.

Bedrock, Vertex AI/Gemini, supporting infrastructure, GPU economics, budgeting, forecasting, anomalies, guardrails, Excel, and PowerPoint are Phase 2 capabilities and are not part of v1.
